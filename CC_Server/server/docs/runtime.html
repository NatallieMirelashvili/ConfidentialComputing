1 · Opening the server

Command: python -m server.main --security tls (or aesgcm). This runs once and builds everything the app will reuse for every request.

#CallFileDoes
1main()main.pyparse --security/host/port (defaults from CONFIG)
2set_event_loop_policymain.pyWindows: silence the TLS-teardown log noise
3create_app(mode)app_server.pybuild the app + singletons for this mode
4get_user_channel()transport/__init__.pypick TlsUserChannel or AesGcmUserChannel (lazy import)
5CollectionService()service.pycreates StubDeviceLink + DataStore
6route registrationapp_server.py/, /api/health, /api/security, /api/devices, /api/collect
7channel.install(app)transport/aesgcm.pyAES-GCM only: add /api/handshake + envelope middleware
8ssl_context() + run()transport/tls.py, main.pyTLS-1.3 context (TLS mode) then start listening

2 · Clicking Collect

The browser sends one POST /api/collect. The TLS and AES-GCM paths differ only at the transport edge; the server logic is identical.

#CallFileDoes
1onCollect() → apiPost()web/app.jsread the dropdowns, send the request
2 aesseal()web/app.jsWebCrypto AES-GCM → {iv, ct} body + X-Session-Id
3 aes_AeadASGIMiddleware.__call__transport/aesgcm.pysession_key() + aead_decrypt() → plain body for the route
4collect(request)app_server.pyparse JSON, call the service, map errors → 400
5CollectionService.collect()service.pyvalidate, orchestrate the 5 steps below
6StubDeviceLink.collect()device_link/stub.py_synthetic_samples() → a Batch (+ verdict)
7DataStore.add() / window()store.pystore the batch, filter to the requested window
8processing.aggregate()processing.pyreduce to the chosen aggregation (e.g. _weighted_avg)

3 · Getting the response

The service's result dict travels back out. Again only the transport edge differs.

#CallFileDoes
1return dictapp_server.pyFastAPI serialises it to JSON
2 aessend_wrapped → aead_encrypt()transport/aesgcm.pybuffer the JSON, encrypt to {iv, ct}, send
3apiPost() → open()web/app.jsAES-GCM: decrypt; TLS: res.json()
4renderResult()web/app.jsshow the value + attested/integrity/measurement chips
