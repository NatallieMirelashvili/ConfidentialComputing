1 · Overview & scope

An IoT edge device (emulated with OP-TEE / ARM TrustZone) collects sensor data and sends it to this Management Server, which serves an end user. This codebase implements the user-facing half only.

In scope (built here)

  • HTML UI + REST API
  • Two swappable User↔Server security modes: TLS 1.3 · AES-256-GCM
  • Collect → store → aggregate (weighted average, mean, …)
  • A stable DeviceLink seam + runnable stub

Out of scope

  • Server↔Device remote attestation
  • Device key exchange & encrypted sensor channel

Sensor data here comes from StubDeviceLink behind the DeviceLink seam; the real device side is a separate part of the project.

2 · Architecture

Every request flows through the selected UserChannel (security), into thin FastAPI routes, to the CollectionService (business logic), and only reaches sensor data through the DeviceLink seam.

3 · The two transport modes

Both satisfy one interface (UserChannel), so the routes are written once. You pick one at launch with --security tls|aesgcm.

6 · Key code walkthrough

One interface, two security modes

class UserChannel(ABC):        # transport/base.py
    def ssl_context(self) -> ssl.SSLContext | None: ...  # TLS returns ctx; AES-GCM None
    def install(self, app): ...   # AES-GCM adds /handshake + middleware
    def describe(self) -> dict: ...  # tells the browser which mode is active

AES-GCM envelope middleware (pure ASGI)

# transport/aesgcm.py — decrypt the request in, encrypt the response out,
# so the routes never change between modes.
plaintext = crypto.aead_decrypt(key, iv, ct, b"")   # request body {iv,ct} -> JSON
...
ct = crypto.aead_encrypt(key, new_iv, response_body, b"")  # -> {iv,ct} on the wire

The seam — the only way sensor data enters

class DeviceLink(ABC):          # device_link/base.py
    async def collect(self, device_id, window) -> Batch: ...
    def status(self) -> dict: ...
# Batch carries the verdict: attested / integrity / measurement_ok

Recency-weighted average

# processing.py — newer samples weigh more (weight grows with timestamp)
for s in samples:
    w = (s.ts - ts_min) + step
    num += w * s.value ; den += w
return num / den

8 · How to run

python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r server/requirements.txt

# TLS 1.3 (default)
python -m server.main --security tls       # https://localhost:8000

# application-layer AES-256-GCM
python -m server.main --security aesgcm     # http://localhost:8000

python -m pytest server/tests -q             # unit + E2E, both modes

Security notes. The TLS cert is self-signed → a one-time local browser warning; the context is TLS-1.3-only. In AES-GCM mode the browser uses WebCrypto (allowed on http://localhost); request/response bodies are {iv, ct} — open devtools → Network to see only ciphertext. All configuration comes from config.Config (MS_* env vars).
